# Adefisayo Adejumo - Portfolio Website

A modern, responsive portfolio website built with React, TypeScript, and Tailwind CSS, featuring beautiful animations, dark mode, and an engaging UI designed to impress recruiters.

## 🚀 Features

- **Auto-typing Hero Section** - Dynamic typing animation showcasing roles and expertise
- **Dark/Light Mode Toggle** - Seamless theme switching with persistent preferences
- **Smooth Animations** - Framer Motion powered animations throughout
- **Interactive Timeline** - Visual career journey and experience showcase
- **Project Showcase** - Featured projects with detailed descriptions
- **Skills Visualization** - Animated progress bars and skill categories
- **Contact Form** - Validated contact form with React Hook Form
- **Fully Responsive** - Mobile-first design that works on all devices
- **Colorful & Creative** - Eye-catching gradients, emojis, and visual elements

## 🛠️ Tech Stack

- **React 18** with **TypeScript**
- **Vite** for fast development and building
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **React Router** for navigation
- **React Hook Form** for form handling
- **React Icons** for beautiful icons
- **React Type Animation** for typing effects

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📝 Customization

To customize the portfolio for your needs:

1. Update personal information in each page component
2. Replace project data in `src/pages/Projects.tsx`
3. Update experience in `src/pages/Experience.tsx`
4. Modify skills in `src/pages/Skills.tsx`
5. Customize colors in `tailwind.config.js`
